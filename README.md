# Project Portfolio Management Dashboard (PPM)

This project delivers a complete **end-to-end data analytics solution** for managing and monitoring a portfolio of projects using **Excel and Power BI**.

---

## 🔧 Tools & Technologies
- Microsoft Excel (Data Cleaning, Validation & Pivot Tables)
- Power Query (ETL & Data Transformation)
- Power BI (Data Modeling, Advanced DAX, Visualization)
- Interactive Dashboards

---

## 📌 Project Workflow
1. Raw data collection from multiple project and task files  
2. Data cleaning and preparation using Excel:
   - Removing duplicates  
   - Handling missing values  
   - Standardizing formats  
   - Applying Data Validation rules  
   - Using Pivot Tables for initial analysis  
3. Data transformation using Power Query (ETL)  
4. Data modeling in Power BI  
5. Creating advanced DAX measures:
   - Cost Variance
   - Budget Utilization %
   - On-Time Completion %
   - Progress & Performance KPIs  
6. Building two professional dashboards:
   - Executive Dashboard
   - Team & Task Performance Dashboard  

---

## 📊 Dashboards Overview

### 1️⃣ Executive Project Insights Dashboard
- Total projects overview  
- Budget vs actual cost  
- Cost variance analysis  
- Budget utilization %  
- Completed vs delayed projects  
- Project distribution by priority and status  
- Monthly performance trends  

---

### 2️⃣ Team & Task Performance Dashboard
- Total, completed, in-progress, and delayed tasks  
- On-time completion %  
- Average task cycle time  
- Budget utilization gauges  
- Team workload distribution  
- Detailed task tracking table
